[April was a perfect 123-for-123](/posts/2026-04-30-github-recap-2026-04/);
May dialed the volume way down — sixty-three PRs, the quietest month of
the year so far — and then quietly did something no month before it had
done: stood up a Kubernetes cluster. Fewer pull requests, bigger
leverage. That's a trade I'd take every month.

Yes, 137 PR reviews on 63 PRs opened — the review-to-authoring ratio
is now officially robot-shaped, with Copilot suggesting and me
adjudicating. The busiest repos were `data-curated` (10),
`www-chicks-net` (9), and `fini-infra` (8). And eight releases in the
"slow" month, because apparently even my off-months ship a release a
week.

## Notable Pull Requests

### [fini-infra #101: our first Kubernetes cluster](https://github.com/fini-net/fini-infra/pull/101)

308 additions creating the first production Kubernetes cluster — the
`k8s-ric1-prod` cluster, closing the same issue #98 that April's VPC
work opened. This is the PR where a repo stops being notes about
infrastructure and becomes infrastructure. The comment thread had an
actual human in it too — me, talking to Claude about cluster naming —
which felt appropriately historical for the occasion.

### [chicks-home #78: add-scorecards](https://github.com/chicks-net/chicks-home/pull/78)

232 additions and the month's liveliest thread (eight comments) for a
new `add-scorecards` command that makes adding OpenSSF Scorecard
workflows to any GitHub repo trivial. I used it on the rest of the
fleet within days — the best measure of a tool PR is how fast the tool
gets used by its own author.

### [chicks-home #77: the repo gets policies](https://github.com/chicks-net/chicks-home/pull/77)

Security policy, code of conduct, codeowners, PR guidelines,
contributing guide — the whole community-health-file suite for my
personal home repo. My dotfiles-adjacent infrastructure now has better
onboarding documentation than most startup codebases. Nobody asked for
this. That's what makes it fun.

Honorable mention to
[fini-infra #109, the deploy-ssh-key PR](https://github.com/fini-net/fini-infra/pull/109),
creating the deployment key in 1Password for the DigitalOcean packer
build — the unglamorous prerequisite work that the cluster PR gets to
stand on. Infrastructure is a tall stack of boring keys and configs,
and I mean that as the highest compliment.
