[January went 130-for-130](/posts/2026-01-31-github-recap-2026-01/) and I
joked that nobody was arguing. February kept the pace at 180 pull requests
and then did something more interesting: half of them went into a single
repo, because `data-curated` decided February was its month. The little
data archive I keep grew a pipeline, a version 1.0, and its first robot.

Ninety of those 180 PRs landed in `data-curated`, 51 more in
`gh-observer`, and 20 here on the blog. That concentration is what a
"focus month" looks like in my world — two projects absorbing nearly
everything. Note the reviews-given number waking up from January's zero:
54, because the interactive Copilot workflow from January's notable PRs
started earning its keep. Also note that final row. There's exactly one
bot-filed data update in February, and there's a story behind it.

## Releases Shipped

### data-curated v0.8, v0.9, and v1.0

Three releases in eight days —
[v0.8 on February 13](https://github.com/chicks-net/data-curated/releases/tag/v0.8),
[v0.9 on the 17th](https://github.com/chicks-net/data-curated/releases/tag/v0.9),

The v1.0 changelog tells the automation story all by itself: unique
branch names for multiple runs in one day, repo-compliant PR titles
generated by the update job itself. That's the changelog of software
that has learned to run without adult supervision.

[chicks-home v42.1](https://github.com/chicks-net/chicks-home/releases/tag/v42.1)
rounds out the month — version 42-point-anything being, of course, the
correct version number.

## Notable Pull Requests

### [data-curated #134: automate the daily update](https://github.com/chicks-net/data-curated/pull/134)

115 lines that changed the shape of every month after it. This PR wired
the daily GitHub-data update to run and file its own pull request, and
on February 17 the robot filed its first one — tagged "manual run," the
way proud parents caption first steps. By fall the dailies would be
filing thirty-some PRs a month without a human touching them. The
"bot-filed data updates" row in these tables starts here.

### [data-curated #101: smarter fetch-commits](https://github.com/chicks-net/data-curated/pull/101)

281 additions teaching the commit fetcher to walk further back in
history before hitting GitHub's API limits — the five-comment thread
most-discussed of the month, including an actual back-and-forth about
pagination strategy. Every data pipeline eventually meets its rate
limit; this one met it and kept going.

### [data-curated #96: YouTube videos become blog posts](https://github.com/chicks-net/data-curated/pull/96)

333 additions generating blog-post drafts straight from YouTube video
data — because if the video has already been made, the metadata might
as well write the post. Between this and the daily update robot,
February is the month my data repo started doing my writing homework.

### [www-chicks-net #282: Backing into Parking Spaces](https://github.com/chicks-net/www-chicks-net/pull/282)

1,182 additions and 543 deletions — the month's biggest blog PR by a
country mile — for [the parking post](/posts/2026-02-01-backing-into-parking-spaces/),
my deeply researched defense of backing into parking spaces. Yes, there
are citations. No, I will not be taking questions.

Quietly, underneath all that, gh-observer had a 51-PR feature sprint
that didn't ship a release all month: switching to GraphQL so it could
show workflow names, error logs for failed jobs, time-since-push in the
header, and a DRY refactor of the view code. That groundwork is where
March's v3.x releases came from. Patience, then payoff.
